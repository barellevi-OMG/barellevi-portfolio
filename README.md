# Technology Portfolio

A public static portfolio showcasing infrastructure engineering, systems integration, automation, technical operations, and technical leadership.

## Explore

- Homepage and project catalog: `/`
- Career tracks: `/infrastructure/`, `/automation/`, `/operations/`, `/leadership/`
- Generalized interactive network architecture: `/examples/network-design/`
- Role-specific routes under `/for/`

## Technology

HTML, CSS, JavaScript and original SVG diagrams. No server-side runtime, client data, production network configuration, credentials, or environment variables are required.

## Build and validation

- `node --check src/app.js`
- `node --check src/data.js`
- `node tests/public-check.mjs`

Static site published from the `gh-pages` branch with GitHub Pages. Source for the public website is the same as the deployment source; review the security and publication policy before adding material.

## Media

Third-party hardware product photos are attributed in [HARDWARE_IMAGE_SOURCES.md](HARDWARE_IMAGE_SOURCES.md). The photos depict reference products, not the exact installed units. Local diagrams are illustrations, not documentation of a deployed infrastructure.

## Security and content publication

See [PUBLICATION_POLICY.md](PUBLICATION_POLICY.md). Report unintended disclosures privately through GitHub's private vulnerability reporting where available; never include credentials or private details in public issues.
