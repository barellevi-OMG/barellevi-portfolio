# Reporting a security issue

Please do not post passwords, keys, access tokens, private addresses, customer data, or proof-of-concept exploit details in a public issue.

If you discover a potential disclosure in this website, contact the repository maintainer through a private security advisory or other non-public channel. Remove exposed credentials from use, rotate affected secrets, and examine repository history, pull-request references, build artifacts and previous deployments.

This is a public static portfolio and should contain no operational secrets. Diagram nodes and traffic paths are illustrative.
